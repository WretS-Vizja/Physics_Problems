# 7. Standing Wave Modes

## Problem
A standing wave with four antinodes is produced on a string of length L = 80 cm. What is the wavelength of this wave?

## Solution

**Step 1 — Boundary conditions of a string fixed at both ends.**  
For a string of length $L$ with both ends fixed, the allowed standing-wave modes have wavelengths

$$\lambda_n = \frac{2L}{n},\quad n = 1, 2, 3, \ldots$$

where $n$ is the mode number, and **$n$ also equals the number of antinodes** (and the number of half-wavelengths that fit in $L$).

**Step 2 — Relate antinodes to the mode number.**  
Four antinodes $\Rightarrow n = 4$.

Graphically, the string contains $n = 4$ half-wavelengths:

$$L = n \cdot \frac{\lambda}{2}$$

**Step 3 — Solve for the wavelength.**  

$$\lambda = \frac{2L}{n} = \frac{2 \times 0.80\ \text{m}}{4} = 0.40\ \text{m}$$

**Step 4 — Quick verification.**  
Four half-wavelengths of $0.40\ \text{m}$ span $4 \times 0.20\ \text{m} = 0.80\ \text{m} = L$. ✓

## Answer

$$\boxed{\lambda = 0.40\ \text{m} = 40\ \text{cm}}$$

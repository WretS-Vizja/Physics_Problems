## Viewing the interactive HTML animations

GitHub does not render `<script>` tags inside repository pages, so the HTML files are not interactive when viewed directly on github.com. Choose one of the following:

### Option A — GitHub Pages (recommended)

1. Go to **Settings → Pages** in your repository.
2. Under **Source**, select `Deploy from a branch`, choose `main`, folder `/ (root)`.
3. Save and wait 1–2 minutes.

Then your animations are live at:

```
https://wrets-vizja.github.io/Physics_Problems/docs/en/Your_solutions/03_Waves_solution/09_damped_oscillator.html
https://wrets-vizja.github.io/Physics_Problems/docs/en/Your_solutions/03_Waves_solution/10_wave_sources.html
https://wrets-vizja.github.io/Physics_Problems/docs/en/Your_solutions/03_Waves_solution/11_young_double_slit.html
```

You can embed these links as buttons in any `.md` file:

```markdown
[▶ Run the damped oscillator](https://wrets-vizja.github.io/Physics_Problems/docs/en/Your_solutions/03_Waves_solution/09_damped_oscillator.html)
```

### Option B — htmlpreview.github.io (no setup)

Prepend `https://htmlpreview.github.io/?` to the raw-file URL:

```
https://htmlpreview.github.io/?https://github.com/WretS-Vizja/Physics_Problems/blob/main/docs/en/Your_solutions/03_Waves_solution/09_damped_oscillator.html
```

### Option C — raw.githack.com (faster CDN)

```
https://raw.githack.com/WretS-Vizja/Physics_Problems/main/docs/en/Your_solutions/03_Waves_solution/09_damped_oscillator.html
```

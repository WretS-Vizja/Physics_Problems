# 2. String Harmonics

## Problem
A guitar string is 64 cm long and has a fundamental frequency (one antinode) of 330 Hz. What is the speed of the wave on this string?

## Solution

**Step 1 — Fundamental mode of a fixed-end string.**  
A string fixed at both ends with **one antinode** vibrates in its fundamental mode. In this mode the string length holds exactly half a wavelength:

$$L = \frac{\lambda}{2} \quad\Longrightarrow\quad \lambda = 2L$$

**Step 2 — Compute the wavelength.**  

$$\lambda = 2 \times 0.64\ \text{m} = 1.28\ \text{m}$$

**Step 3 — Use $v = f\lambda$.**  

$$v = f\lambda = 330\ \text{Hz} \times 1.28\ \text{m}$$

**Step 4 — Final numerical value.**  

$$v = 422.4\ \text{m/s}$$

## Answer

$$\boxed{v \approx 422\ \text{m/s}}$$
